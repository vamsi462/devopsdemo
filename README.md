# DevOps Git Assignment Demo

This repository was created as part of the DevOps Workshop Training. It demonstrates core Git version control operations including repository initialization, branching, merging, and file tracking.

## Tools Used
* Google Cloud Platform (Compute Engine)
* Ubuntu 22.04 LTS
* Git
* Vim Editor

## Included Files
* `iFile1.txt` & `iiFile2.txt` (Created in master branch)
* `File3.txt` & `File4.txt` (Created in feature1 branch, merged to master)
